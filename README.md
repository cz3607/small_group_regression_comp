Our Process:
First, we imported the data. Then, we found the columns with missing values and decided which of those columns to drop from the data. We also determined that the existence of a fireplace and a pool may be useful to the analysis, so we decided to fill all the missing values with “None.” After we dropped our columns and modified FireplaceQu and PoolQC, we separated the rest of the categories with missing values into lists of numerical and categorical columns. For the numerical columns, we filled in the missing values with the mean. For the categorical columns, we filled in the missing values with the most frequently appearing value in that column. Afterwards, we picked some columns representing quality (KitchenQual and HeatingQC) that we wanted to ordinally encode and created an ordinal encoder using the values of Po, Fa, Gd, TA, Ex as a scale for how good the quality is. After this, we identified the columns that we wanted to ordinally encode and one hot encode from the columns that had missing values in them and added the columns that we wanted to ordinally encode and one hot encode from the columns that didn’t have missing values. Then, we combined everything from before together into a pipeline. We made a variable called cols that includes all the columns that we want to use and set X equal to a dataframe made of those columns from the training data. We set y equal to a dataframe with just the SalePrice from the training data. Afterwards, we used the pipeline to predict the value of y using the test data and put that into a new dataframe called pdf, which we also added an Id column to based on the index. This pdf column is then saved as preds.csv and is what we submitted to Kaggle. After we made the initial first CSV, we decided to test adding and dropping variables to the model to see if it resulted in a smaller mean squared error by comparing the solutions’ SalePrice to our pdf’s SalePrice. If we got a larger MSE, we would revert the change of either adding or dropping a variable. If we got a smaller MSE, we would keep the change.
